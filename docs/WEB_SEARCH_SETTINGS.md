# Free web-search settings

Dashboard controls:

- [x] Google
- [x] Bing
- [x] Yahoo

Mode:
- Fallback (default): query enabled engines in order Google -> Bing -> Yahoo and stop when an engine returns useful results.
- Search All: query every enabled engine, combine results, then deduplicate URLs.

All three are direct/free result-page adapters for the MVP. There is no paid API or proxy fallback. CAPTCHA/rate-limit protections are not bypassed.

Search-engine results are discovery evidence only. Candidate websites still require identity verification.
